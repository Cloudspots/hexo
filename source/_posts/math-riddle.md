甲、乙、丙、丁、戊五人各从图书馆借来一本小说，约定读完后相互交换。$5$ 本书的厚度与 $5$ 人的阅读速度都差不多，因此 $5$ 个人总是同时交换书。经 $4$ 次交换后，每个人都读完了这 $5$ 本书，已知：

1. 甲最后读的书是乙读的第二本书。
2. 丙最后读的书是乙读的第四本书。
3. 丙读的第二本书是甲读的第一本书。
4. 丁最后读的书是丙读的第三本书。
5. 乙读的第四本书是戊读的第三本书。
6. 丁读的第三本书是丙读的第一本书。

则丁读的第二本书是 ____ 最先读的。

---

根据题意，我们可以列出表格：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $G$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ |  |  |  |
| **第五次** | $G$ |  | $M$ | $L$ |  |

一共有 $A,C,G,L,M$ 五种字母。

> 至于我为什么不用 $A,B,C,D,E$，大家可以猜猜，答案放在最后。

这里注意，虽然书也是五本，但是可没有保证是一一对应的。

我们看看哪些可能相等吧，显然在同一行或者同一列是不能相等的。

经过枚举，可以发现，$C,G$ 是可能相等的。

但是我们不妨假设一一对应。

### 假设一一对应

那么可以推出丙第四次读了 $G$：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $G$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ | $G$ |  |  |
| **第五次** | $G$ |  | $M$ | $L$ |  |

我们发现这里有三个 $M$，不妨看看哪里不能有 $M$：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ | $\color{red}\xcancel M$ | $C$ |  | $\color{red}\xcancel M$ |
| **第二次** |  | $G$ | $A$ |  | $\color{red}\xcancel M$ |
| **第三次** | $\color{red}\xcancel M$ | $\color{red}\xcancel M$ | $L$ | $C$ | $M$ |
| **第四次** | $\color{red}\xcancel M$ | $M$ | $C$ | $\color{red}\xcancel M$ | $\color{red}\xcancel M$ |
| **第五次** | $G$ | $\color{red}\xcancel M$ | $M$ | $L$ | $\color{red}\xcancel M$ |

非常好，因为这里有 $3$ 个 $M$，所以剩下两个，显然只能是甲的第二次和丁的第一次：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ | $M$ |  |
| **第二次** | $M$ | $G$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ | $G$ |  |  |
| **第五次** | $G$ |  | $M$ | $L$ |  |

还有三个 $G$，你一定能猜到我想干什么：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ | $\color{red}\xcancel G$ | $C$ | $M$ |  |
| **第二次** | $M$ | $G$ | $A$ | $\color{red}\xcancel G$ | $\color{red}\xcancel G$ |
| **第三次** | $\color{red}\xcancel G$ | $\color{red}\xcancel G$ | $L$ | $C$ | $M$ |
| **第四次** | $\color{red}\xcancel G$ | $M$ | $G$ | $\color{red}\xcancel G$ | $\color{red}\xcancel G$ |
| **第五次** | $G$ | $\color{red}\xcancel G$ | $M$ | $L$ | $\color{red}\xcancel G$ |

哎呀，这里应当再填两个 $G$，但是只有一个位置，导出矛盾。

### 不是一一对应

为了让你不用翻，我这里再贴一次原本的表格：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $G$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ |  |  |  |
| **第五次** | $G$ |  | $M$ | $L$ |  |

显然，只有 $C$ 和 $G$ 可能相等，那么会有一本书不是 $A,B,C,L,M$ 中的任何一种，记作 $\alpha$。

我们可以把所有 $G$ 替换成 $C$：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $C$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ |  |  |  |
| **第五次** | $C$ |  | $M$ | $L$ |  |

这样，我们就有了四个 $C$，可以一看看出来剩下的 $C$ 在哪：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $C$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ |  |  | $C$ |
| **第五次** | $C$ |  | $M$ | $L$ |  |

然后，丙的第四次就应该是 $\alpha$：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ |  |  |
| **第二次** |  | $C$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ | $\alpha$ |  | $C$ |
| **第五次** | $C$ |  | $M$ | $L$ |  |

现在，表格中不同的元素就互不相同了。

同样，我们标出不可能是 $M$ 的地方：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ | $\color{red}\xcancel M$ | $C$ |  | $\color{red}\xcancel M$ |
| **第二次** |  | $C$ | $A$ |  | $\color{red}\xcancel M$ |
| **第三次** | $\color{red}\xcancel M$ | $\color{red}\xcancel M$ | $L$ | $C$ | $M$ |
| **第四次** | $\color{red}\xcancel M$ | $M$ | $\alpha$ | $\color{red}\xcancel M$ | $C$ |
| **第五次** | $C$ | $\color{red}\xcancel M$ | $M$ | $L$ | $\color{red}\xcancel M$ |

所以，还是这两个地方是 $M$：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ | $M$ |  |
| **第二次** | $M$ | $C$ | $A$ |  |  |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ | $\alpha$ |  | $C$ |
| **第五次** | $C$ |  | $M$ | $L$ |  |

看似没有什么突破口了，那我们标记不能是 $L$ 的地方：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ |  | $C$ | $M$ |  |
| **第二次** | $M$ | $C$ | $A$ | $\color{red}\xcancel L$ |  |
| **第三次** | $\color{red}\xcancel L$ | $\color{red}\xcancel L$ | $L$ | $C$ | $M$ |
| **第四次** |  | $M$ | $\alpha$ | $\color{red}\xcancel L$ | $C$ |
| **第五次** | $C$ | $\color{red}\xcancel L$ | $M$ | $L$ | $\color{red}\xcancel L$ |

看来我们的运气还不错，显然可行的只有这一种：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ | $L$ | $C$ | $M$ |  |
| **第二次** | $M$ | $C$ | $A$ |  | $L$ |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** | $L$ | $M$ | $\alpha$ |  | $C$ |
| **第五次** | $C$ |  | $M$ | $L$ |  |

这题的答案也就几乎给你了，我们可以推出戊第一次，丁第二次：

|  | 甲 | 乙 | 丙 | 丁 | 戊 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **第一次** | $A$ | $L$ | $C$ | $M$ | $\alpha$ |
| **第二次** | $M$ | $C$ | $A$ | $\alpha$ | $L$ |
| **第三次** |  |  | $L$ | $C$ | $M$ |
| **第四次** | $L$ | $M$ | $\alpha$ |  | $C$ |
| **第五次** | $C$ |  | $M$ | $L$ |  |

所以，丁读的第二本是 $\alpha$，戊读的第一本是 $\alpha$，答案是：戊。
