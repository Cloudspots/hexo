# ARC226 ABC 题解

## A

首先我们划分为若干个段，按照所有时间的并集来划分。两个不同段之间互不相交，而一个段之内所有区间并也是一个区间。

对于每个段，我们取第一个区间和所有和它有交的区间。如果所有和它有交但和它不同的区间不两两无交则无解，否则我们取最后一个区间作为第一个区间，然后删掉前面的区间继续操作。

注意每一轮可能会有矛盾，所以我们需要构造方案，然后判断是否矛盾。

如果没有矛盾就是 $2^{t}$，其中 $t$ 是我们划分的段数。

## B

首先有一个显然的贪心就是从大到小，每次选择目前权值最小的。

考虑优化。首先如果 $\max - \min < v$（$v$ 是目前的权值）那么直接全局加法然后 $a$ 对 $n$ 取模。然后考虑用优先队列维护一些数字，$\lvert a,b\rvert$ 代表 $b$ 个 $a$ 即可。用小根堆。

懒得分析复杂度，能过。

## C

好玩！！

首先 $n,m$ 都是偶数那么你直接 $2\times 2$ 铺过去就可以了。

如果 $n$ 是奇数，$m$ 是偶数也是 $2\times 2$ 铺过去。这是因为，每一列都至少有一个不选的，这种铺过去的方案可以卡到下界。

如果 $n,m$ 都是奇数呢？这个比较困难了。直接铺过去是不行的。

我们先考虑 $n=m$。

$n=3$ 是平凡的……等等，它真的平凡吗？

我们一眼就可以看出来最优解只能有一个正方形，但是这没有卡到理论最优，即每行每列都只有一个格子没有选。我们先放着。

$n=5$？

通过暴力或者手动模拟可以得到这样一组解：

:::info[$n=5$]{open}

```plaintext
122.1
.2233
44.33
4455.
1.551
```

:::

得到 $5$，我们直接铺过去只有 $4$。

我们想这样是不是就是最优解了呢？可以考虑 $n=7$。

:::info[$n=7$]{open}
```plaintext
12266.1
.226633
99xx.33
99xx.77
55...77
558844.
1.88441
```
:::

注意这里是一个圈，里面一个 $3\times 3$ 的情况。而 $n=9$ 呢？

:::info[$n=9$]{open}
```plaintext
12299dd.1
.2299dd55
aaeff.e55
aa.ffii88
66gg.ii88
66gghh.cc
33e.hhecc
33bb7744.
1.bb77441
```
:::

注意这是一个圈里面一个 $5\times 5$。

那么 $n\equiv 1\pmod 4$ 已被解决，是最优解。$n\equiv 3\pmod 4$ 呢？我们猜想这个取不到最优解。当然，我们的圈圈递归构造还是可以给出一个次优的解。

:::info[$n\equiv 3\pmod 4$ 时最优解有 $n+4$ 个点未被选中]

我们只需要证明 $n$ 个点不可行。$n+4$ 个点的构造参见圈圈。

如果 $n$ 个点可行，那么说明一共有 $n^2-n=n(n-1)$ 个点被选中。注意到 $n(n-1)\equiv 2\pmod 4$，矛盾！

:::

这样我们就给出了 $n=m$ 的构造。

对于 $n<m$，我们猜想就是 $n=m$ 的构造再往后铺。对于 $n\equiv 1\pmod 4$ 的时候这个最优性也是显然的。对于 $n\equiv 3\pmod 4$ 的时候？

:::info[$n<m$ 且 $n\equiv 3\pmod 4$ 时最优解至少有 $m+4$ 个点未被选中]

同理只需证 $m$ 个点不可行。

如果 $m$ 个点可行，则一共有 $(n-1)m$ 个点被选中，$(n-1)m\equiv 2\pmod 4$，矛盾！

:::

$n>m$ 同理略去。

综上我们解决了这道题。时间复杂度 $O(nm)$。
