要做这道题，很好的一个办法是把比较 $k$ 比较大的图画出来，方法有很多，我自己用的是 Python（虽然我很不熟练，毕竟我常用的是 C++），这是 $k=5$ 时的气球：

[![pkvshIP.png](pkvshIP.png)](https://imgse.com/i/pkvshIP)

当然，我们一看到 $k \in [0,30]$ 的时候就知道绝对不能模拟了，需要用数学一点的办法。

我们看到这一行“第 $A \sim B$ 行一共有多少个红气球”的时候，发现是区间求和，很自然的就想到前缀和。

于是就设 $S_{k,i}$ 为气球分裂 $k$ 次，前 $i$ 行的红气球个数。

我们先做些铺垫，显然有：
1. $S_{k, 0} = 0$，一行都不选。
1. $S_{0, 1} = 1$，气球不分裂，并且选取全部。
1. $S_{k, 2^k} = 3^k$，一共分裂 $k$ 次，有 $2^k$ 行，也就相当于全选。而每次一个红气球分裂成三个蓝气球，并且没有其他的方式获得红气球，所以全选的红气球个数是 $3^k$。

那么，如何求出 $S_{k, i}$ 呢？

我们可以用分治的思想。假设我们要求下图黄色框中的红气球个数：

[![pkvsDPK.png](pkvsDPK.png)](https://imgse.com/i/pkvsDPK)

我们可以把要求的地方分为两部分：

[![pkvsjI0.png](pkvsjI0.png)](https://imgse.com/i/pkvsjI0)

上半部分同样可以分为一样的左右两部分，这里图就不贴了。显然，两部分的红色气球个数都是 $S_{k-1, 2^{k-1}}$，而根据我们上面做的铺垫中的第三条，有 $3^{k-1}$ 个，总共有 $2 \times 3^{k-1}$ 个。

而对于下半部分，首先，易知，它的右半部分一定全是蓝色气球，所以我们就当右半部分不存在。

[![pkvsWVI.png](pkvsWVI.png)](https://imgse.com/i/pkvsWVI)

于是我们同样可以将其分为上下两部分，上面可以直接求，下面再次递归计算。

但是，对于这个例子是这样，对于所有的情况是否都是这样分为上下两部分计算呢？好问题。

易得，凡是占了整个大正方形的一半以上的都是可以分割的，因为分割线就是大正方形的一半。

所以说，凡是只占了一个正方形的一半以内的，就是不能分割的。

然而，如果我们碰到一个不能分割的，是不是就不能计算了呢？显然不是。

因为，凡是不能直接分割计算的，**必然可以分为左右两部分**。为什么呢，因为它们都是同样颜色的红气球分裂同样的次数取的同样的行啊！所有条件都一样，红气球个数怎么可能不一样呢？

所以，我们就可以将其分割为左右两部分，然后……同样可以递归计算。

这道题就搞完啦~不过答案爆 int，可以用 long long。

（我第一次提交居然把 `Case` 写成了 `case`！）

求 $S_{k,i}$ 的代码：
```cpp
long long S(int k, int i)
{
	long long res;
	if (i == 0) res = 0;
	else if (k == 0 && i == 1) res = 1;
	else if (i == (1 << k)) res = qpow(3, k); //qpow是快速幂
	else if (i <= (1 << (k - 1))) res = 2 * S(k - 1, i);
	else res = 2 * qpow(3, k - 1) + S(k - 1, i - (1 << (k - 1)));
	//printf("S(%d, %d) = %lld\n", k, i, res);
	return res;
}
```
