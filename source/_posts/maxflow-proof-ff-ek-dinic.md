# 最大流，最大流最小割定理，Ford–Fulkerson，Edmonds-Karp，和 Dinic！

特别鸣谢：算法导论。

## 什么是最大流

试想你有一个无向图，每条边上有一个容量。

这个无向图中有一个起点和一个终点，你要把一些货物沿着边把起点运输到终点，但是每条边承载的货物量不能超过容量。

注意，你没必要只选择一条路径，你可以同时利用很多边。比如 $1\to 2$ 权值为 $2$，$2\to 3$ 和 $2\to 4$ 权值为 $1$，$3\to 4$ 权值为 $2$，起点为 $1$，终点为 $4$。最好的方法是除了 $3\to 4$ 实际运送货物为 $1$ 之外让所有其它边满载。

看起来很简单的问题，但是其实并不简单。

## 贪心？

我们考虑每次找到一条起点到终点，所有边没有满载的路径，直到起点无法走到终点为止。这就是贪心。

很遗憾，这是错的。比如，$1\to 2,1\to 3,2\to 4,2\to 5,3\to 4,4\to 5$ 所有边权值均为 $1$，起点为 $1$，终点为 $5$，最优解是利用 $1\to 2\to 5$ 和 $1\to 3\to 4\to 5$，但是第一步可能找出 $1\to 2\to 4\to 5$，容量只有 $1$，但是之后起点到终点就不连通了。

### 反悔贪心！

我们考虑给贪心增加反悔的过程。

对于每条原图上实际的边 $u\to v$，容量为 $c$，流量（这条遍目前流的货物）$k$，原本我们的做法很简单粗暴——如果 $k=c$ 就不连边，否则连 $u\to v$ 并且权值为 $c-k$。

现在我们还需要撤销一条边的流量。那么我们在 $k\neq 0$ 的时候再建一条边 $v\to u$，权值为 $k$。这样，我们增广（找一条路径的过程）的时候如果走了 $v\to u$ 就会撤销这条边的流量。

为了使流网络简单，我们假设没有反平行边，即原图不能同时存在 $u\to v$ 和 $v\to u$。如果有，我们可以建一个虚拟点 $x$，把 $v\to u$ 变为 $v\to x\to u$，容量为原本 $v\to u$ 的容量。

诶等等，这样做出来的真的是合法的流吗？其实是。我们假设 $c_f(u,v)$ 是残差网络（我们按照上面的两条边方法建出来的图）上 $u\to v$ 的边权，如果不存在这条边即为 $0$。同时，$f(u,v)$ 是 $u\to v$ 的实际流量，$c(u,v)$ 是 $u\to v$ 的容量。那么有对于存在的边 $u\to v$，我们有 $c_f(u,v)=f(u,v)$，同时 $c_f(v,u)=c(u,v)-f(u,v)$。

我们形式化一个网络合法的条件。

1. $0\le f(u,v)\le c(u,v)$，即不能超载，也不能流一个负数。这一点是显然的。
2. $\forall x\not\in \{s,t\},\sum f(y,x)=\sum f(x,y)$。也就是说除了起点和终点，所有的点都只能是中转，流入的货物必须流出，也不能凭空制造货物。

我们考虑路径上所有非起点非终点的点。这次增广以后，若路径上它的上一条边指向它，则它会增加这次增广的边权（设为 $v$）的货物。如果路径上它的上一条边的起点是它，则增广后它会少运走 $v$ 的货物，总而言之还是增加了 $v$ 的货物。同理考虑下一条边，会让这个点多运走 $v$ 的货物，所以流量守恒得到了保持。

而对于起点和终点，根据上面的讨论，会增加 $v$ 的流量。

所以整个网络的流量增加了 $v$，并且仍然合法。

### 它会不会结束？

这还真是个问题。

对于整数边权，它必然会结束。这是因为，最大流最多就是边权之和，而每次最大流最少也要增加 $1$，所以必然结束。

对于有理数边权，也必然会结束。我们全部乘一个大数就变成了整数边权。

对于无理数则不一定，我懒得给 hack 了。

我们每次找增广路的时候随便找，这就是 Ford–Fulkerson 算法。它的时间复杂度很劣，在整数边权的时候是 $O(Ef)$ 的，其中 $f$ 是最大流大小。其实，Ford–Fulkerson 方法是对于下面所有算法（包括 Ford–Fulkerson 算法）的统称。因为它们本质上都是不断寻找增广路，只不过寻找的增广路不同，或是寻找的方式不同。

### 我该怎么写代码？

找到“反向边”这个操作在我惯用的邻接表中并不好做。邻接矩阵，这个太劣了。但是在链式前向星中，我们可以直接把一条边和反向边放在一起。如果我们从 $0$ 开始编号，那么一条边的编号异或 $1$ 之后恰好是其反向边的编号。

## 正确性？

等等，就算边权都是有理数甚至是整数，为什么上面得到的是最大流？

这需要下面的定理来保证。

### 最大流最小割定理

首先我们定义切割的概念：把节点分成两个集合 $S,T$，起点属于 $S$，终点属于 $T$。

然后我们定义切割的净流量：原图上所有 $S\to T$ 的边的流量之和减去所有 $T\to S$ 的边的流量之和。

还有切割容量：所有 $S\to T$ 的边的容量之和。

我们有一个 key observation：一个切割的净流量一定等于整个网络的流量。

证明非常简单，我们把所有边分成四类：$S\to S,S\to T,T\to S,T\to T$。我们把 $S$ 看成一个大点，$T$ 看成一个大点，那么自己到自己的流量没有意义，只有 $S\to T$ 的有意义。但是 $T\to S$ 又运回来了，所以总流量就是 $S\to T$ 的总流量减去 $T\to S$ 的总流量。当然也可以代数证明。

同时我们发现切割的净流量一定不能超过切割的容量。所以说，任意流的大小也不能超过任意切割的容量。

那么接下来我们给出最大流最小割定理。

:::info[最大流最小割定理]{open}

下面三个陈述是等价的：

1. $f$ 是图的一个最大流。
2. $f$ 的残差网络中不存在增广路。换句话说，$f$ 的残差网络上起点走不到终点。
3. $f$ 的大小等于图中某个切割的容量。

证明：

- $1\Rightarrow 2$：若存在增广路，则必然不是最大流。$\square$
- $2\Rightarrow 3$：我们构造切割 $S$ 为残差网络上所有从起点可达的点，$T$ 为所有其它点，显然终点不在 $S$ 中。那么我们考虑这个残差网络中必然不能存在 $S\to T$ 的边，否则违反了 $S$ 的定义。所以这个切割的容量就是原图上 $S$ 到 $T$ 的边的容量之和。同时对于 $f$ 的大小就是这个切割的净流量，由于残差网络上没有 $S\to T$ 的边，那么原图上所有 $S\to T$ 的边都是满载的，且没有 $T\to S$ 的边。所以这个切割的净流量就是所有 $S\to T$ 的边的容量之和，也就是这个切割的容量。$\square$
- $3\Rightarrow 1$：显然对于所有流，它的流量都一定 $\le$ 所有切割的容量。那你就然都取到等于了，必然就是最大流。$\square$。

推论：$2\Rightarrow 1$，即如果不存在增广路，则一定是最大流。

:::

我们就证明了它的正确性。

## 优化！

直接 Ford–Fulkerson 显然是很慢的。我们考虑通过寻找一些比较优秀的增广路来加速。

### Edmods–Karp

我们每次使用 BFS 找到边数最少的增广路。

我们有关键的性质：从起点 $s$ 到任何节点，增广后的最短路长度必然不降。

首先我们需要说明这并不是显然的，因为增广有可能增加边。

:::info[Proof]

考虑反证。假设 $G$ 为原残差网络，$G'$ 为一次使 $s$ 到某些点流量减少的增广之后的残差网络。假设 $v$ 是所有使 $d_G(s,u)>d_{G'}(s,u)$ 的 $d_{G'}(s,u)$ 最小的点（$d$ 是距离），如果有多个就取任意一个。

同时设 $u$ 为 $G'$ 中 $s\leadsto v$ 的任意一条路径上倒数第二个点（也就是 $v$ 的前一个点）。显然，$d_{G'}(s,u)=d_{G'}(s,v)-1$，那么 $d_G(s,u)\le d_{G'}(s,u)$。

同时，若 $G$ 中存在 $u\to v$ 的边（$G'$ 中显然存在），那么 $d_G(s,v)\le d_G(s,u)+1\le d_{G'}(s,u)+1=d_{G'}(s,v)$，矛盾了。所以 $G$ 中必然不存在 $u\to v$ 的边。

等等，$G$ 中不存在 $u\to v$，但是 $G'$ 中存在？说明这条增广路包含了 $v\to u$。因为我们增广走的是最短路，所以必然有 $d_G(s,u)=d_G(s,v)+1$，那么 $d_G(s,v)=d_G(s,u)-1\le d_{G'}(s,u)-1=d_{G'}(s,v)-2$，等等你怎么矛盾了？$\square$

:::

同时，我们发现每一次增广至少要从残差网络中删去一条边，因为这条边变成 $0$ 了。我们称这样的边为“关键边”。我们试图证明，每一条边成为“关键边”的次数是 $O(V)$ 的。具体来讲，最多是 $\dfrac{V}{2}$。

:::info[Proof]

我们考虑 $u\to v$ 成为关键边。它下一次成为关键边必须是 $v\to u$ 成为关键边。那么，假设第一次成为关键边之前是图 $G$，第二次之前是 $G'$。那么，$d_{G'}(s,u)=d_{G'}(s,v)+1\ge d_G(s,v)+1=d_G(s,u)+2$。但是，$d$ 最多是 $V$，所以最多成为 $\dfrac{V}{2}$ 次关键边。

:::

所以所有边一共最多成为 $O(VE)$ 次关键边。每次 BFS 时间复杂度 $O(E)$，总时间复杂度就是 $O(VE^2)$。

以上内容全部参考自《算法导论》。

### Dinic

本节内容参考自刘汝佳《算法竞赛入门经典 训练指南》和 OI-wiki。

主播主播，你的 EK 时间复杂度和最大流大小无关是很优秀，但还是太慢了，有没有更快的做法？

有的兄弟，有的。我们可以每次增广多条路径！

我们每次构造残差网络后构造 BFS 层次图。具体来讲，只保留每一层到下一层的边，同层之间不保留。

然后我们在这个构造出的 DAG 上 DFS，每次找到一条增广路就增广。一轮 DFS 过程中总共找出的流称作阻塞流。容易发现，每一轮 DFS 完之后所有起点到终点的最短路都断了，而新出来的反向边并不会有任何用处。所以，起点到终点的最短路长度至少增加 $1$。也就是说最多会有 $O(V)$ 次 DFS（和 BFS，但是 BFS 时间复杂度可以忽略不计）。

同时我们还有一个优化——当前弧优化。如果这个节点的一些出边已经满了，下次就不遍历。在代码上我们对于每个节点记一个值代表这个节点前几条边已经满了。

我们考虑这个 DFS 的复杂度是什么。

与 EK 类似，每一次找增广路都会删掉至少一条边，所以最多 $O(E)$ 条增广路。我们考虑没有死胡同的情况，此时每次寻找都只用花费 $O(V)$ 的时间。现在有死活同，但是死胡同会被当前弧优化优化掉，总共只会浪费 $O(E)$ 的时间，总时间复杂度 $O(VE)$。

一共有 $O(V)$ 次增广，总时间复杂度 $O(V^2E)$。

我们还有一个常数优化——多路增广。找到一条增广路之后我们直接回溯回去找另一条，而不是再从头开始。注意区分多路增广和当前弧优化，当前弧优化保证了复杂度，但是多路增广只是常数优化。

看起来并不是很优秀，但实际上这个算法在实际情况中跑得非常快，并且基本没有人会去卡。实际上，它在很多特殊情形下复杂度都是对的。比如在单位容量的网络中，时间复杂度是 $O(E\min(E^{\frac{1}{2}},V^{\frac{2}{3}}))$ 的。同时，如果在单位容量的网络中，除了源点和汇点之外所有点入度或者出度都为 $1$，则时间复杂度是 $O(E\sqrt V)$，常用于二分图最大匹配。

// Dinic
#include <queue>
#include <cstdio>
#include <cstring>

using namespace std;

const auto U = [](auto x) { return [x](auto ...y) { return x(x, y...); }; };

int head[205];
class edge { public: int v; long long cap; int nxt; } edges[10005];
int qhead[205];
int dist[205];

int main()
{
  int n, m, s, t;
  scanf("%d%d%d%d", &n, &m, &s, &t);
  memset(head, -1, sizeof head);
  int cur = 0;
  auto addedge = [&cur](int u, int v, long long w)
  {
    edges[cur] = {v, w, head[u]};
    head[u] = cur;
    cur++;
  };
  for(int i=1;i<=m;i++)
  {
    int u, v, w;
    scanf("%d%d%d", &u, &v, &w);
    addedge(u, v, w);
    addedge(v, u, 0);
  }
  // Dinic
  auto bfs = [&]() -> bool // BFS & Initialization & Check
  {
    // printf("!\n");
    memset(dist, 0x3f, sizeof dist);
    dist[s] = 0;
    queue<int> q;
    q.push(s);
    while(!q.empty())
    {
      int u = q.front();
      q.pop();
      for(int vid = head[u]; vid != -1; vid = edges[vid].nxt)
      {
        if(edges[vid].cap != 0 && dist[u] + 1 < dist[edges[vid].v])
        {
          dist[edges[vid].v] = dist[u] + 1;
          q.push(edges[vid].v);
        }
      }
    }
    if(dist[t] == 0x3f3f3f3f) return false; // Disconnected
    for(int i=1;i<=n;i++) qhead[i] = head[i];
    return true;
  };
  auto dfs = U([&](auto &&self, int u, long long val) -> long long
  {
    if(u == t) return val;
    long long sum = 0;
    for(; qhead[u] != -1; qhead[u] = edges[qhead[u]].nxt)
    {
      if(dist[u] + 1 != dist[edges[qhead[u]].v] || !edges[qhead[u]].cap) continue;
      long long res = self(self, edges[qhead[u]].v, min(edges[qhead[u]].cap, val - sum));
      edges[qhead[u]].cap -= res;
      edges[qhead[u] ^ 1].cap += res;
      sum += res;
      if(sum == val) return sum;
    }
    return sum;
  });
  long long sum = 0;
  while(bfs()) sum += dfs(s, 0x3f3f3f3f3f3f3f3f);
  printf("%lld\n", sum);
  return 0;
}
